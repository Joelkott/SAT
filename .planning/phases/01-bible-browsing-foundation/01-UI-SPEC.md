## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline icon gaps, verse number margin-right |
| sm | 8px | Compact element spacing, button padding-y, gap between language pills, tab bar gaps |

## Layout

### BiblePanel Structure

Primary focal point: the verse display area is the primary visual anchor of the BiblePanel. All navigation (book list, chapter grid, breadcrumb) serves to populate and direct attention to the verse display content area.

```
+--------------------------------------------------+
| [Translation Selector v]    [Reference Search___] |
| ------------------------------------------------ |
| Genesis > Chapter 3                    (breadcrumb)|
| ------------------------------------------------ |
| +-------------+  +------------------------------+ |
| | Book List   |  | Verse Display                | |
| | (scrollable)|  | "John 3:16 (KJV)"           | |
| |             |  |                              | |
| | [Genesis]   |  | 16 For God so loved...       | |
| | Exodus      |  | 17 For God did not send...   | |
| | Leviticus   |  |                              | |
| | ...         |  |                              | |
| +-------------+  +------------------------------+ |
+--------------------------------------------------+
```

| Property | Value |
|----------|-------|
| Panel container | Full width below tab bar, `space-y-4` vertical flow |
| Left column (books) | 200px fixed width, scrollable, shows when no chapter selected |
| Right column (content) | Flex-grow, fills remaining width |
| Responsive | Below 768px: stack vertically, book list collapses to dropdown |
| Navigation flow | Book list -> Chapter grid -> Verse display (replaces content area at each step) |

### Navigation State Machine

```
[No selection] -> [Book selected: show chapter grid] -> [Chapter selected: show verses]
```

- Back navigation via breadcrumb clicks
- Book list remains visible on desktop as sidebar; chapter grid and verse display share the main content area

## Interaction States

### Loading

| Trigger | Indicator | Location |
|---------|-----------|----------|
| Fetching translations | Spinner + "Loading..." | Translation selector area |
| Fetching books | Spinner + "Loading..." | Book list area |
| Fetching chapters | Spinner + "Loading..." | Main content area |
| Fetching verses | Spinner + "Loading..." | Main content area |
| Reference search | Spinner + "Loading..." | Main content area |

Spinner: 16px CSS spinner (`animate-spin` on a border-based circle), `text-gray-400`.

### Error

All errors display inline (not modal/alert), as a card with:
- `bg-red-900/20 border border-red-800/30 rounded-lg p-4`
- Error text in `text-red-300 text-sm`
- "Try again" link in `text-red-400 hover:text-red-300 underline`

### Keyboard

| Key | Action | Context |
|-----|--------|---------|
| Enter | Submit reference search | Reference input focused |
| Escape | Clear reference search input | Reference input focused |
