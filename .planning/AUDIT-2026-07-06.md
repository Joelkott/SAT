## Known issues — NOT fixed (decisions/scope)

1. **No authentication on any endpoint** (delete songs, reindex, drive ProPresenter, trigger backups). Fine for isolated LAN; add a token if the network is shared. Biggest remaining risk.
2. **5 npm vulns require Next.js 16** (breaking major). Advisories target features unused here (image optimizer, middleware, i18n, WS). Schedule the upgrade deliberately.
3. **Migrations only run on first Postgres volume init** — future `002_*.sql` will silently not apply. Adopt golang-migrate (or similar) before the next schema change.
4. **pg_dump gets full DSN on argv** (password visible in container process list). Low risk in-container; switch to PGPASSWORD env if hardening further.
5. **ProPresenter handlers return raw err.Error()** (internal host:port leak). Cosmetic infoleak.
6. Scroll-sync sender in SongsPanel has no receiver in display window (dead feature).
7. verseUtils treats any literal `[n]` in verse text as a marker (rare translation edge case).
8. Songs list loads entire library, no pagination/virtualization — fine at hundreds, revisit at thousands.
9. public/fonts (Anjali/Mangal) shipped but no @font-face — Malayalam/Hindi rendering depends on client OS fonts.
10. Credentials in `.env` were historically logged (DSN) — rotate DB/Typesense/api.bible keys when convenient.

## Verified safe

- SQL fully parameterized (no injection). No XSS (React text rendering, no dangerouslySetInnerHTML). No shell injection (exec argv). `.env` never committed to git. Embedded KJV/MOV load in ~160ms at boot (negligible); work fully offline. api.bible/Typesense outages now degrade gracefully.
