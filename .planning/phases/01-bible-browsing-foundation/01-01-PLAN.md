**models.go** — Go structs matching api.bible JSON responses. Package name: `bible`.

```go
// Bible represents a translation/version
type Bible struct {
    ID                string   `json:"id"`
    Name              string   `json:"name"`
    NameLocal         string   `json:"nameLocal"`
    Abbreviation      string   `json:"abbreviation"`
    AbbreviationLocal string   `json:"abbreviationLocal"`
    Description       string   `json:"description"`
    DescriptionLocal  string   `json:"descriptionLocal"`
    Language          Language `json:"language"`
}

type Language struct {
    ID        string `json:"id"`
    Name      string `json:"name"`
    NameLocal string `json:"nameLocal"`
    Script    string `json:"script"`
    Direction string `json:"scriptDirection"`
}

// Book represents a Bible book
type Book struct {
    ID           string `json:"id"`           // e.g., "GEN"
    BibleID      string `json:"bibleId"`
    Abbreviation string `json:"abbreviation"` // e.g., "Gen"
    Name         string `json:"name"`         // e.g., "Genesis"
    NameLong     string `json:"nameLong"`     // e.g., "The First Book of Moses, called Genesis"
}

// Chapter represents a chapter in a book
type Chapter struct {
    ID        string `json:"id"`        // e.g., "GEN.1"
    BibleID   string `json:"bibleId"`
    BookID    string `json:"bookId"`
    Number    string `json:"number"`
    Reference string `json:"reference"` // e.g., "Genesis 1"
}

// Verse represents a single verse
type Verse struct {
    ID        string `json:"id"`        // e.g., "GEN.1.1"
    OrgID     string `json:"orgId"`
    BibleID   string `json:"bibleId"`
    BookID    string `json:"bookId"`
    ChapterID string `json:"chapterId"`
    Reference string `json:"reference"` // e.g., "Genesis 1:1"
    Text      string `json:"text"`      // plain text, HTML stripped
}

// Passage represents a range of verses
type Passage struct {
    ID        string `json:"id"`
    BibleID   string `json:"bibleId"`
    OrgID     string `json:"orgId"`
    Reference string `json:"reference"`
    Content   string `json:"content"`   // plain text, HTML stripped
}

// API response wrappers (api.bible nests data under "data" key)
type BiblesResponse struct {
    Data []Bible `json:"data"`
}

type BooksResponse struct {
    Data []Book `json:"data"`
}

type ChaptersResponse struct {
    Data []Chapter `json:"data"`
}

type ChapterContentResponse struct {
    Data struct {
        ID        string `json:"id"`
        BibleID   string `json:"bibleId"`
        BookID    string `json:"bookId"`
        Number    string `json:"number"`
        Reference string `json:"reference"`
        Content   string `json:"content"`
    } `json:"data"`
}

type VersesResponse struct {
    Data []Verse `json:"data"`
}

type VerseResponse struct {
    Data Verse `json:"data"`
}

type PassageResponse struct {
    Data Passage `json:"data"`
}
```

**cache.go** — In-memory TTL cache using sync.Map (per D-06). Two TTL durations: `MetadataTTL = 24 * time.Hour` and `ContentTTL = 1 * time.Hour`.

```go
type cacheEntry struct {
    data      interface{}
    expiresAt time.Time
}

type Cache struct {
    store sync.Map
}

func NewCache() *Cache
func (c *Cache) Get(key string) (interface{}, bool)  // returns nil, false if expired or missing
func (c *Cache) Set(key string, data interface{}, ttl time.Duration)
func (c *Cache) Delete(key string)
```

Get checks expiration and deletes expired entries on access (lazy cleanup).

**client.go** — api.bible HTTP client following propresenter/client.go pattern (per D-04, D-05).

```go
type Config struct {
    APIKey  string // from API_BIBLE_KEY env var
    BaseURL string // from API_BIBLE_BASE_URL env var, default "https://api.scripture.api.bible/v1"
}

type Client struct {
    baseURL    string
    apiKey     string
    httpClient *http.Client
    cache      *Cache
}

func New(config *Config) *Client  // returns nil-safe client if config nil
func (c *Client) IsConfigured() bool

// All methods return Go structs, not raw JSON
func (c *Client) GetBibles() ([]Bible, error)                              // GET /v1/bibles, cached MetadataTTL
func (c *Client) GetBooks(bibleID string) ([]Book, error)                  // GET /v1/bibles/{bibleId}/books, cached MetadataTTL
func (c *Client) GetChapters(bibleID, bookID string) ([]Chapter, error)    // GET /v1/bibles/{bibleId}/books/{bookId}/chapters, cached MetadataTTL
func (c *Client) GetChapterContent(bibleID, chapterID string) (*ChapterContentResponse, error)  // GET /v1/bibles/{bibleId}/chapters/{chapterId}?content-type=text, cached ContentTTL
func (c *Client) GetVerse(bibleID, verseID string) (*Verse, error)         // GET /v1/bibles/{bibleId}/verses/{verseId}?content-type=text, cached ContentTTL
func (c *Client) GetPassage(bibleID, passageID string) (*Passage, error)   // GET /v1/bibles/{bibleId}/passages/{passageId}?content-type=text, cached ContentTTL
```

Every method:
1. Checks cache first (key format: `"bibles"`, `"books:{bibleID}"`, `"chapters:{bibleID}:{bookID}"`, etc.)
2. On miss, makes HTTP GET to api.bible with header `api-key: {apiKey}`
3. Decodes JSON into response wrapper struct, extracts `.Data`
4. For content endpoints, strips any residual HTML tags using a simple regex `<[^>]*>` before caching
5. Caches result with appropriate TTL
6. Returns data or error

HTTP client timeout: 15 seconds. All errors wrapped with `fmt.Errorf("bible: failed to ...: %w", err)`.

**handlers.go** (new file in `backend/internal/bible/`) — Fiber route handlers.

Create a `BibleHandler` struct holding `*Client`:

```go
type BibleHandler struct {
    client *Client
}

func NewHandler(client *Client) *BibleHandler

// Route handlers — each returns JSON via c.JSON()
func (bh *BibleHandler) GetBibles(c *fiber.Ctx) error       // GET /api/bible/bibles -> calls client.GetBibles()
func (bh *BibleHandler) GetBooks(c *fiber.Ctx) error        // GET /api/bible/bibles/:bibleId/books -> calls client.GetBooks(bibleId)
func (bh *BibleHandler) GetChapters(c *fiber.Ctx) error     // GET /api/bible/bibles/:bibleId/books/:bookId/chapters -> calls client.GetChapters(bibleId, bookId)
func (bh *BibleHandler) GetChapter(c *fiber.Ctx) error      // GET /api/bible/bibles/:bibleId/chapters/:chapterId -> calls client.GetChapterContent(bibleId, chapterId)
func (bh *BibleHandler) GetVerse(c *fiber.Ctx) error        // GET /api/bible/bibles/:bibleId/verses/:verseId -> calls client.GetVerse(bibleId, verseId)
func (bh *BibleHandler) GetPassage(c *fiber.Ctx) error      // GET /api/bible/bibles/:bibleId/passages/:passageId -> calls client.GetPassage(bibleId, passageId)
```

Each handler:
1. Extracts path params via `c.Params("bibleId")` etc.
2. Calls the corresponding client method
3. On error: returns `c.Status(502).JSON(fiber.Map{"error": "Failed to fetch ..."})` (502 since it's a proxy error)
4. On success: returns `c.JSON(data)` (the Go struct, not wrapped)
